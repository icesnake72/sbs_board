# 기술 스택

출처: `build.gradle`, `src/main/resources/application.yaml`

## 런타임

| 항목 | 버전 / 값 |
|---|---|
| Java | **21** (toolchain) |
| Spring Boot | **3.5.14** |
| Spring Dependency Management | 1.1.7 |
| 빌드 도구 | Gradle (Wrapper 포함) |
| DB | MySQL (`com.mysql:mysql-connector-j`) |
| 서버 포트 | 8090 |

`compileJava`에 `-parameters` 옵션이 켜져 있다 → `@PathVariable` 등에서 파라미터명 생략 가능.

## 의존성

| 의존성 | 용도 |
|---|---|
| `spring-boot-starter-web` | REST API, 내장 Tomcat |
| `spring-boot-starter-security` | 인증/인가 필터 체인, `@PreAuthorize` |
| `spring-boot-starter-oauth2-client` | 카카오/구글 소셜 로그인 (OAuth2 + OIDC) |
| `spring-boot-starter-data-jpa` | Hibernate ORM, `JpaRepository` |
| `spring-boot-starter-validation` | `@Valid`, Jakarta Bean Validation |
| `io.jsonwebtoken:jjwt` 0.12.6 | JWT 생성/검증 (`api` + `impl` + `jackson`) |
| `lombok` | 보일러플레이트 제거 |
| `spring-boot-devtools` | 개발 중 자동 재시작 |
| `spring-security-test` | 테스트 (현재 테스트는 컨텍스트 로딩 1건뿐) |

## 애플리케이션 전역 설정

`BoardApplication.java`

```java
@EnableJpaAuditing          // @CreatedDate / @LastModifiedDate 활성화
@ConfigurationPropertiesScan // KakaoOAuthProperties 스캔
@SpringBootApplication
```

`WebConfig.java`

```java
@EnableSpringDataWebSupport(pageSerializationMode = VIA_DTO)
```

→ `Page<T>` 응답이 **DTO 형태**로 직렬화된다. 응답 스키마는 [[API-페이지네이션]] 참조.

## JPA 설정

| 키 | 값 | 의미 |
|---|---|---|
| `spring.jpa.hibernate.ddl-auto` | `update` | 엔티티 변경 시 테이블 자동 반영 (운영 부적합) |
| `dialect` | `MySQLDialect` | |
| `show_sql` / `format_sql` | `true` | 콘솔에 SQL 출력 |

## 파일 업로드 제한

| 키 | 값 |
|---|---|
| `spring.servlet.multipart.max-file-size` | **2MB** (파일 1개당) |
| `spring.servlet.multipart.max-request-size` | **20MB** (요청 전체) |
| 코드상 이미지 개수 제한 | **5장** (`PostController.MAX_IMAGES`) |

## JWT 설정

| 키 | 값 |
|---|---|
| `jwt.secret` | Base64 인코딩된 HS256 키 (**소스에 하드코딩됨** → [[알려진-이슈]]) |
| `jwt.access-token-validity-seconds` | `3600` (1시간) |
| `jwt.refresh-token-validity-seconds` | `36000` (10시간) |
