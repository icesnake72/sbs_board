# 로컬 실행 가이드

## 사전 요구사항

| 항목 | 버전 |
|---|---|
| JDK | **21** |
| MySQL | 8.x (로컬 3306) |
| Gradle | Wrapper 포함 — 별도 설치 불필요 |

## 1. 데이터베이스 준비

```sql
CREATE DATABASE board DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

접속 정보는 `application.yaml`에 **하드코딩**되어 있다.

```yaml
spring.datasource:
  url: jdbc:mysql://localhost:3306/board?serverTimezone=Asia/Seoul&characterEncoding=UTF-8
  username: root
  password: 1234
```

다르다면 `application.yaml`을 수정하거나 실행 시 오버라이드한다.

```bash
./gradlew bootRun --args='--spring.datasource.password=yourpassword'
```

테이블은 `ddl-auto: update`로 **자동 생성**된다.

## 2. 환경변수 파일

프로젝트 루트에 `.env`를 만든다 (`.gitignore` 대상).

```properties
KAKAO_REST_API=your_kakao_rest_api_key
KAKAO_SECRET=your_kakao_client_secret
KAKAO_CALLBACK=http://localhost:8090/api/oauth/kakao/callback
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
APP_UPLOAD_DIR=./uploads
```

로딩 설정:

```yaml
spring.config.import: optional:file:.env[.properties]
```

⚠️ `optional:`이지만 **`KakaoOAuthProperties`가 `@PostConstruct`에서 값을 검증**하므로
카카오 3개 키가 없으면 **애플리케이션이 기동되지 않는다**.

```
InternalException: 설정값 로딩 실패
```

소셜 로그인을 쓰지 않더라도 더미 값이라도 채워야 한다. → [[환경변수]]

## 3. 실행

### Gradle

```bash
# Windows (PowerShell)
.\gradlew.bat bootRun

# Git Bash / macOS / Linux
./gradlew bootRun
```

### IntelliJ IDEA

`BoardApplication.java` → ▶ Run

`spring-boot-devtools`가 포함되어 있어 클래스 변경 시 자동 재시작된다.

### 확인

```bash
curl http://localhost:8090/api/board/all
# → []
```

## 4. 초기 데이터 만들기

시딩 스크립트가 없으므로 API로 만든다.

### (1) 관리자 계정 생성

```bash
curl -X POST http://localhost:8090/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@test.com","password":"admin1234","nick_name":"관리자","role":"ADMIN"}'
```

> `role`을 클라이언트가 지정할 수 있어서 가능한 방법이다. 이는 보안 결함이며 [[알려진-이슈]] BE-02에 기록되어 있다.
> 정상화되면 DB에서 직접 `UPDATE users SET role='ADMIN' WHERE email='admin@test.com';` 로 승격해야 한다.

### (2) 로그인 → 토큰 획득

```bash
curl -X POST http://localhost:8090/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@test.com","password":"admin1234"}'
```

응답의 `accessToken`에는 이미 `"Bearer "`가 포함되어 있다.

### (3) 게시판 생성

```bash
TOKEN="Bearer eyJhbGciOi..."

curl -X POST http://localhost:8090/api/board/new \
  -H "Content-Type: application/json" \
  -H "Authorization: $TOKEN" \
  -d '{"name":"자유게시판","description":"자유롭게 이야기하세요"}'
```

### (4) 게시글 작성 (이미지 포함)

```bash
curl -X POST http://localhost:8090/api/post/1/new \
  -H "Authorization: $TOKEN" \
  -F 'post={"title":"첫 번째 게시글","body":"본문입니다"};type=application/json' \
  -F 'images=@./sample.png'
```

`post` 파트에 `;type=application/json`을 붙여야 한다.

### (5) 댓글 작성

```bash
curl -X POST http://localhost:8090/api/comment/post/1/new \
  -H "Content-Type: application/json" \
  -H "Authorization: $TOKEN" \
  -d '{"content":"첫 댓글입니다"}'
```

## 5. 업로드 디렉터리

`APP_UPLOAD_DIR` (기본 `./uploads`)이 기동 시 자동 생성된다.
`/images/{storedName}`으로 서빙된다.

⚠️ `uploads/`가 `.gitignore`에 없다 → 업로드 파일이 커밋될 수 있다. 아래를 추가하는 것을 권장한다.

```gitignore
uploads/
```

## 6. 로그 확인

```yaml
logging.level:
  com.sbs.board: DEBUG
  org.springframework.security.web.FilterChainProxy: DEBUG
```

SQL도 콘솔에 출력된다 (`show_sql: true`, `format_sql: true`).

## 7. 테스트

```bash
./gradlew test
```

현재 `BoardApplicationTests`(컨텍스트 로딩) 하나뿐이다.
`.env`가 없으면 이 테스트도 실패한다 (카카오 프로퍼티 검증 때문).

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `InternalException: 설정값 로딩 실패` | `.env`에 `KAKAO_REST_API`/`KAKAO_SECRET`/`KAKAO_CALLBACK` 누락 |
| `Communications link failure` | MySQL 미기동 또는 접속정보 불일치 |
| `Unknown database 'board'` | `CREATE DATABASE board;` 실행 |
| `Table doesn't exist` | `ddl-auto: update` 확인. 첫 기동 로그에서 DDL 확인 |
| 한글 깨짐 | DB charset을 `utf8mb4`로 생성했는지 확인 |
| 브라우저에서 API 호출 시 CORS 에러 | 서버에 CORS 설정이 없다 → 개발 프록시 사용. [[API-클라이언트-가이드]] |
| `GET /api/user/me` 가 500 | 알려진 버그. [[API-User]] |
| 이미지가 404 | `APP_UPLOAD_DIR` 경로와 `WebConfig`의 리소스 핸들러 경로 확인 |
