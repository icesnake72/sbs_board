# 환경변수 · 설정

## 로딩 방식

```yaml
# application.yaml
spring:
  config:
    import: optional:file:.env[.properties]
```

프로젝트 루트의 `.env`를 **properties 형식**으로 읽는다 (`KEY=value`, 따옴표·`export` 없음).
`.gitignore`에 포함되어 있다.

## .env 키 목록

| 키 | 필수 | 용도 | 예시 |
|---|---|---|---|
| `KAKAO_REST_API` | ✅ | 카카오 REST API 키 (OAuth2 client-id + 수동 구현 appkey) | `a1b2c3...` |
| `KAKAO_SECRET` | ✅ | 카카오 Client Secret | `x9y8z7...` |
| `KAKAO_CALLBACK` | ✅ | 레거시 수동 구현 콜백 URL | `http://localhost:8090/api/oauth/kakao/callback` |
| `GOOGLE_CLIENT_ID` | ⚠️ | 구글 OAuth 클라이언트 ID | `...apps.googleusercontent.com` |
| `GOOGLE_CLIENT_SECRET` | ⚠️ | 구글 Client Secret | |
| `APP_UPLOAD_DIR` | ❌ | 업로드 경로 (기본 `./uploads`) | `./uploads` |

### 왜 카카오 키가 "필수"인가

`KakaoOAuthProperties`가 `@PostConstruct`에서 값을 검증한다.

```java
private static void requireResolve(String name, String value) {
    if (value == null || value.isBlank() || value.contains("${")) {
        throw new InternalException("설정값 로딩 실패");
    }
}
```

값이 없으면 플레이스홀더 `${KAKAO_REST_API}`가 그대로 남아 **애플리케이션 기동이 실패**한다.
소셜 로그인을 쓰지 않더라도 더미 값이라도 넣어야 한다.

구글 키는 이런 검증이 없지만, 없으면 `/oauth2/authorization/google` 호출 시 실패한다.

## application.yaml 주요 설정

### 서버

```yaml
server.port: 8090
```

### 데이터소스 (⚠️ 하드코딩)

```yaml
spring.datasource:
  url: jdbc:mysql://localhost:3306/board?serverTimezone=Asia/Seoul&characterEncoding=UTF-8
  username: root
  password: 1234
```

**환경변수로 분리되어 있지 않다.** 운영 배포 전에 반드시 외부화해야 한다.

```yaml
# 권장
url: ${DB_URL:jdbc:mysql://localhost:3306/board?...}
username: ${DB_USERNAME:root}
password: ${DB_PASSWORD:1234}
```

### JPA

```yaml
spring.jpa:
  hibernate.ddl-auto: update      # ⚠️ 운영에서는 validate 또는 none + 마이그레이션 도구
  properties.hibernate:
    dialect: org.hibernate.dialect.MySQLDialect
    show_sql: true                # ⚠️ 운영에서는 false
    format_sql: true
```

### 파일 업로드

```yaml
spring.servlet.multipart:
  max-file-size: 2MB      # 파일 1개당
  max-request-size: 20MB  # 요청 전체
```

코드상 이미지 개수 제한은 5장(`PostController.MAX_IMAGES`)이다.

### JWT (⚠️ 시크릿 하드코딩)

```yaml
jwt:
  secret: c2VjcmV0X2tleV9ieV9zYnNfYWNhZGVteV8yMDI2MDcyMV9ib2FyZF9iYWNrX2VuZF9hcHA=
  access-token-validity-seconds: 3600    # 1시간
  refresh-token-validity-seconds: 36000  # 10시간
```

🚨 **시크릿이 Git에 커밋되어 있다.** Base64 디코딩하면 사람이 읽을 수 있는 문자열이다.
운영 전 반드시 환경변수로 분리하고 값을 교체해야 한다. → [[알려진-이슈]] BE-06

```yaml
# 권장
jwt.secret: ${JWT_SECRET}
```

### Refresh 쿠키

```yaml
app.refresh-cookie:
  name: refreshToken
  secure: false        # ⚠️ 운영: true (HTTPS)
  same-site: Strict    # ⚠️ 크로스 오리진 프론트엔드에서는 쿠키 미전송
  path: /api/auth
```

프론트엔드를 별도 오리진에서 띄운다면 이 값들을 조정해야 한다. → [[토큰-저장-전략]]

### 업로드 경로

```yaml
app.upload.dir: ${APP_UPLOAD_DIR:./uploads}
```

`FileStorageService`(저장)와 `WebConfig`(정적 서빙) 양쪽이 이 값을 참조한다.

### OAuth2 클라이언트

```yaml
spring.security.oauth2.client:
  registration:
    kakao:
      client-id: ${KAKAO_REST_API}
      client-secret: ${KAKAO_SECRET}
      redirect-uri: "{baseUrl}/login/oauth2/code/kakao"
      authorization-grant-type: authorization_code
      client-authentication-method: client_secret_post
      scope: profile_nickname          # ⚠️ 이메일 미포함
    google:
      client-id: ${GOOGLE_CLIENT_ID}
      client-secret: ${GOOGLE_CLIENT_SECRET}
      scope: openid,profile,email
  provider:
    kakao:
      authorization-uri: https://kauth.kakao.com/oauth/authorize
      token-uri: https://kauth.kakao.com/oauth/token
      user-info-uri: https://kapi.kakao.com/v2/user/me
      user-name-attribute: id
```

⚠️ 카카오 scope에 이메일이 없다. `User.email`이 NOT NULL이므로 카카오 최초 로그인 시 저장이 실패할 수 있다.
카카오 개발자 콘솔에서 이메일 동의항목을 활성화하고 `scope: profile_nickname,account_email`로 변경해야 한다.

### 로깅

```yaml
logging.level:
  com.sbs.board: DEBUG
  org.springframework.web.client: DEBUG
  org.springframework.security.web.FilterChainProxy: DEBUG
```

⚠️ `JwtTokenProvider`가 **시크릿과 토큰 전문을 DEBUG 로그에 출력**한다. 운영에서는 반드시 레벨을 올릴 것.

## 환경별 프로파일 분리 (권장, 미적용)

현재 프로파일 분리가 없다. 아래 구조를 권장한다.

```
application.yaml           # 공통
application-local.yaml     # 로컬 (show_sql, secure=false)
application-prod.yaml      # 운영 (HTTPS, secure=true, ddl-auto=validate)
```

```bash
java -jar board.jar --spring.profiles.active=prod
```
