# Board Backend — LLM Wiki

이 `docs/` 폴더는 **Obsidian Vault** 이자 **Claude Code 참조 문서**입니다.
`com.sbs.board` Spring Boot 백엔드의 구조 · 도메인 · API · 프론트엔드 요구사항을 담고 있습니다.

## 사용 방법

### Obsidian
1. Obsidian 실행 → `Open folder as vault` → 이 `docs` 폴더 선택
2. [[00-Home]] 부터 시작 (Map of Content)
3. 그래프 뷰에서 도메인 ↔ API ↔ 화면 연결 관계를 확인

### Claude Code
- 새 작업을 시작할 때 이 문서들을 먼저 읽히면 코드 탐색 비용이 줄어듭니다.
- 예: `docs/03-API/API-Post.md 읽고 게시글 검색 기능 추가해줘`
- 프론트엔드 작업 시: `docs/04-프론트엔드/ 전부 읽고 Next.js 프로젝트 스캐폴딩 해줘`

## 문서 규칙

| 규칙 | 내용 |
|---|---|
| 링크 | Obsidian 위키링크 `[[문서명]]` 사용 (경로 없이 파일명만) |
| 파일명 | Vault 전체에서 **유일**해야 링크가 깨지지 않음 |
| 코드 위치 | `파일경로:줄번호` 형식으로 표기 (Claude Code에서 클릭 가능) |
| 다이어그램 | ` ```mermaid ` 코드펜스 (Obsidian 기본 렌더링) |
| 사실 표기 | 코드에서 확인된 내용만 기술. 미구현/버그는 [[알려진-이슈]]에 분리 |

## 폴더 구조

```
docs/
├─ 00-Home.md              ← 시작점 (MOC)
├─ 01-아키텍처/            ← 시스템이 어떻게 동작하는가
├─ 02-도메인/              ← 데이터가 무엇인가 (ERD, 엔티티)
├─ 03-API/                 ← 외부에 무엇을 노출하는가
├─ 04-프론트엔드/          ← FE 제작을 위한 요구사항
├─ 05-운영/                ← 실행·환경설정
└─ 99-메타/                ← 이슈, 용어집, 참고자료
```

## 문서 갱신 원칙

코드를 수정하면 아래를 함께 갱신하세요.

- 엔드포인트 추가/변경 → `03-API/` 해당 문서 + [[API-개요]] 표
- 엔티티 필드 변경 → `02-도메인/` 해당 문서 + [[도메인-모델]] ERD
- `ErrorCode` enum 변경 → [[API-에러코드]]
- 버그 수정 → [[알려진-이슈]]에서 해당 항목 제거
- 편집가능한 문서임
